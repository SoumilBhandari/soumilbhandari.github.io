This browser can’t write NFC tags — use the steps below.

On iPhone, or any browser without Web NFC

  1. Install NFC Tools (free, App Store or Play Store).
  2. Write → Add a record → URL/URI.
  3. Enter https://soumilbhandari.github.io and confirm.
  4. Tap Write, then hold the tag to the top of your phone.
  5. Test it with a different phone, then use Other → Lock tag so nobody can overwrite it.
