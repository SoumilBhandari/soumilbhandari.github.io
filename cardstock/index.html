How it works

Three steps, one evening.

1

Edit one file

Your name, your links, your resume. It's plain HTML with the CSS inline — no framework, no build, nothing to install. If you can edit a text file you can ship this.

2

Push it

GitHub Pages serves it free over HTTPS, and points at your own domain if you have one. Deploys land in under a minute.

# live at https://yourname.github.io
git add -A && git commit -m "update" && git push
3

Write the tag

Thirty-three bytes of URL onto a forty-cent chip. The card stores the link, never the data — so a new job title costs you one push, not a reprint. Write it from the browser on Android, or a free app on iPhone.

The physical half

Artwork that a printer will take.

Every file is sized to CR80 — 85.5 × 54 mm, the same as a credit card — with text kept 4 mm inside the trim so nothing important dies at the cut.

  • Trim version for UV printing onto blank NFC cards
  • Bleed version with crop marks outside the bleed, where a printer can see them
  • Engraving artwork for wood and bamboo, sized for a laser's bleed
  • Live vector text and QR — no rasterised type anywhere
  • QR decoded back out of a 300 dpi render, not assumed to work
